# Personal Expense Tracker

A minimal, modern, full-stack Personal Expense Tracker built with **HTML5**, **CSS3**, **Vanilla JavaScript**, **Python (Flask)**, and **SQLite**.

## Quick Start (Windows PowerShell / Command Prompt)

1. Open the project folder in **VS Code** (`File -> Open Folder... -> personal-expense-tracker`).
2. Open the integrated terminal (`Ctrl + ~`) and run:

```powershell
# 1. Create a Python virtual environment
python -m venv venv

# 2. Activate the virtual environment (PowerShell)
.\venv\Scripts\Activate.ps1
# (Or in Command Prompt: venv\Scripts\activate.bat)

# 3. Install Flask and python-dotenv
pip install -r requirements.txt

# 4. Run the Flask server
python app.py
```

3. Open your browser and visit `http://127.0.0.1:5000`.
